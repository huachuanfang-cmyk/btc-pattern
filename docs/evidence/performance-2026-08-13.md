# 移动性能门禁验收：2026-08-13

## 首屏负载治理

- 将 ETH、SOL、DOGE、BNB 的完整历史日线从首屏移除，只在用户选择币种或进行历史横向对比时加载。
- 数据更新任务生成约 2.2KB 的 `data/daily-summary.js`，用于首屏五币种异常信号与保存条件核对。
- `html2canvas` 仅在用户点击“下载 PNG”时加载；报告打开但未下载时不会请求该库。
- 移除外部 Google Fonts 首屏请求，使用稳定的系统字体栈，避免字体替换导致布局偏移。
- 移动端实时行情栏固定为单行横向浏览，三块异步数据区域按响应式断点保留稳定空间。

## 自动预算

`scripts/check-performance.js` 在 390 x 844、2 倍 DPR 的 Chromium 中执行，门禁为：

- 首屏请求不超过 24。
- 传输量不超过 1.25MB。
- LCP 不超过 2.5 秒。
- CLS 不超过 0.1。
- 首屏不得请求 `html2canvas`。

该门禁已加入 GitHub Actions `Product quality gates`，每次 `main` 推送和 Pull Request 执行。

## 结果

优化前本地基线：3.49MB、CLS 0.9672。

优化后本地基线：15 个请求、0.98MB、LCP 228ms、CLS 0、未加载报告渲染器。

线上 `https://www.mybtcbox.com/`：

- 15 个请求。
- 252,875 字节传输量。
- LCP 1,312ms。
- CLS 0.0751。
- 首屏未加载报告渲染器。

完整功能回归与 360、390、768、1440 四种宽度浏览器验收为 32/32 通过；报告 PNG 按需加载流程四种宽度全部通过。

## 评分边界

移动端：9.5/10。响应式、触控、核心路径、故障降级和线上性能预算均有自动证据。10 分仍需两台真实手机的系统分享与安装体验长期验证。

SEO 获客：9.0/10。技术性能与可索引工具页已通过，但没有 Search Console 收录和至少 30 天自然搜索数据，因此不超过 9.0。
