# 核心工具任务验收记录：2026-08-13

## 验收范围

浏览器从真实首页依次完成四类核心任务：

- 查询 BTC 单日收盘跌幅的历史规律。
- 按指定日期生成 BTC、ETH、SOL、DOGE、BNB 五币对比。
- 运行定投回测并得到触发次数与收益率。
- 生成包含查询条件、样本和方法限制的报告卡片。

测试使用页面真实按钮和 DOM 结果，不绕过产品控制器。计时从按钮已进入视口后的真实点击开始，到用户可见结果完成为止；五币对比的首个样本包含数据冷加载。页面自动滚动到按钮的时间不计作按钮响应时间。

## 结果

桌面 1440px 项目对每项任务连续运行 20 次，共 80 次任务：

| 任务 | 成功率 | p95 响应 |
| --- | ---: | ---: |
| 历史查询 | 100% | 277ms |
| 五币对比 | 100% | 49ms |
| 定投回测 | 100% | 52ms |
| 生成报告 | 100% | 49ms |

所有任务均超过 95% 成功率要求，p95 均低于 1 秒，且过程中没有页面脚本异常。

## 持续门禁

`tests/e2e/core-tasks.spec.js` 固化上述任务、样本量、成功率与 p95 阈值，并随完整 Playwright 套件在 CI 中运行。已有响应式套件继续在 360、390、768、1440 四种宽度验证核心入口、结果布局、数据加载失败状态与报告弹窗边界。
