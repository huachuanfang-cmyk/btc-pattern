# 用户粘性验收记录：2026-08-11

## 每日价值

- 首页每日观察摘要基于最新完整 UTC 日线更新。
- 展示BTC日线涨跌、距样本高点回撤、回撤日变化和周期计时。
- 五币种完整日线异常信号每天自动核对。

## 本地个性化

- 用户可以保存最多5个常用查询条件。
- 每日观察摘要显示已保存条件数量和当天触发数量。
- 本设备记录连续查看的完整数据日，重复渲染或刷新不会重复增加。
- 保存条件、观察日期和连续天数只保存在浏览器 localStorage，不上传服务器。
- 每个保存条件直接显示在第一屏摘要中，逐项标注“已触发”或“未触发”，点击后恢复并运行对应历史查询。
- 条件状态按钮在 360、390、768 和 1440 四种宽度下保持可用，触控高度至少 44px。

## 分享回访

- 第一屏提供“分享今日观察”，分享文案包含完整日线日期、日线涨跌、距样本高点、周期天数和个人条件触发数。
- 分享固定链接保留 `view=daily`、数据日期和来源标记。
- 分享文案固定说明“历史数据仅供参考，不预测涨跌”。
- 支持系统分享；不可用时降级复制到剪贴板，失败时向用户显示明确提示。

## 回访入口

- 网站提供 Web App Manifest、Service Worker和“固定到主屏幕”入口。
- 安装后提供历史大跌查询、周期刻度和条件回测三个快捷方式。
- Service Worker使用网络优先策略，网络正常时不会优先返回旧日线。
- Chromium所需的192×192和512×512非透明PNG图标均已部署。
- iOS提供180×180 Apple Touch Icon。

## 移动端验收

- 390px宽度无横向溢出。
- 保存条件和安装入口文字保持12px。
- 操作按钮实际触控高度为44px。

## 自动化证据

- 连续两个完整数据日会把本地连续记录从1增加到2。
- 同一个数据日重复渲染不会继续增加。
- 保存和删除查询会立即刷新每日摘要。
- 每日摘要个人条件、状态、分享入口、分享日期和预测边界均有回归测试。
- Playwright 20/20 通过；线上 390px 浏览器确认条件状态、44px 触控高度、分享入口和零横向溢出。
- Manifest图标尺寸、RGB非透明格式、快捷入口和Service Worker网络优先顺序都有回归测试。

- 首次访问不展示虚构的“上次来访”内容；只有本设备已经记录过完整日线日期，且出现新日线后才显示。
