# 小型无障碍验收记录：2026-08-14

## 范围

本次只修复自动可验证的交互可访问性，不调整页面信息架构、品牌色、字体系统、URL、分析事件或报告内容。页面继续使用深色背景、橙色强调色、紧凑数据布局和现有圆角规则。

## 修复内容

- 所有按钮最小高度统一为44px，历史查询筛选框最小高度为44px。
- 按钮、链接、选择框和输入框在 `:focus-visible` 时显示2px橙色轮廓，并保留2px间距。
- 报告弹窗增加 `dialog`、`aria-modal`、双语可访问名称和说明关联。
- 打开报告后焦点进入第一个操作按钮；Tab 和 Shift+Tab 在弹窗内循环。
- Esc 可关闭报告；关闭后焦点返回原来的“生成报告卡片”或“生成回测报告”按钮。
- 弹窗关闭时恢复 `aria-hidden=true`，避免隐藏内容进入辅助技术阅读顺序。

## 失败测试优先

实现前新增浏览器验收并在390px项目运行。测试按预期失败，首次发现语言按钮高度只有22px。修复后同一测试在360、390、768和1440四档全部通过。

## 自动验收

浏览器专项逐档检查：

- 所有可见按钮具有文本或 `aria-label`。
- 语言按钮、阈值按钮、筛选框、保存按钮和报告按钮的触控高度不低于44px。
- 关键控件文本与有效背景的对比度不低于4.5:1。
- 键盘焦点轮廓宽度不低于2px。
- 报告弹窗名称、初始焦点、正反向焦点循环、Esc关闭和焦点归还正确。

完整 Playwright 结果：58项通过，6项按既有环境条件跳过。360、390、768、1440四档全部通过；历史查询、五币对比、回测和报告任务成功率均为100%。

## 限制

- 本次没有进行人工屏幕阅读器测试，也没有据此提高任何评分。
- 颜色检查覆盖主要交互控件，不等同于逐像素审计全部报告图片文字。
- 真实手机的系统分享、安装和辅助技术长期验收仍是移动端后续证据缺口。
