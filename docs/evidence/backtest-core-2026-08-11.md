# 回测核心验收记录：2026-08-11

## 独立模块

`assets/backtest-core.js` 不访问 DOM、localStorage 或页面全局状态。所有函数通过日线、日期、阈值、金额和分档规则参数运行。

覆盖能力：

- 目标日期没有日线时使用其后第一根可用日线。
- 每周定投避免多个计划日期重复使用同一根日线。
- 普通条件买入按收盘价成交。
- 分档买入按前收盘与阈值计算触发价，同一天可成交多个档位。
- 年度结果使用累计持币、累计投入和年度末价格计算累计收益率。
- 月度触发和月度收益只纳入存在有效数据的月份。
- 组合最大回撤使用历史组合价值的运行高点。

## 边界测试

- UTC 闰年日期加法。
- 数据集之前、之间和之后的目标日期。
- 空组合回撤返回有限的中性结果。
- 恰好 `-20%` 的回撤计入阈值，避免浮点误差漏计。
- 首年从用户选择日期开始，后续年份使用完整可用区间。
