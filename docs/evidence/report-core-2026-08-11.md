# 报告统计核心验收记录：2026-08-11

## 独立统计

`assets/report-core.js` 不访问页面或浏览器存储，独立计算：

- 样本期最高价、最低价、最大单日上冲和最大单日下探。
- 总收益、平均日涨跌和平均绝对波动。
- 七档日涨跌分布，所有有效日线只归入一个区间。
- 最长连续上涨与下跌，以及不同持续天数的次数。
- 年度收益、日波动、上涨天数、下跌天数和 YTD 标识。
- 超过 20% 的重大回撤、最深回撤和高点到底部天数。
- 月度平均收益、上涨月份比例和有效样本数。

## 确定性复算

测试使用跨 2023、2024、2025 的小型日线样本，验证：

- 年度收益使用上一年最后收盘作为完整年度基准。
- 月度收益使用上一月最后收盘作为基准。
- 未恢复的重大回撤只计为一个连续回撤期。
- 空数据返回完整的中性结构，不产生 `NaN` 或异常。
- 区间边界不会重复计数或漏计。

## 当前限制

- PNG 分享图仍需多设备像素密度与长图清晰度验收。
