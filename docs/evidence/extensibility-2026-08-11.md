# 代码扩展性验收记录：2026-08-11

## 模块边界

- `index.html` 只保留语义化页面结构、SEO 元数据和资源装配。
- `assets/app.css` 独立维护整站视觉与响应式规则。
- `assets/core.js` 维护不依赖 DOM 的 OHLC 标准化、事件统计、未来收益、日期、周期、每日观察、回访和条件触发计算。
- `assets/backtest-core.js` 独立维护条件买入、每周定投、分档买入、年度与月度对比和组合回撤。
- `assets/report-core.js` 独立维护极值、涨跌分布、连续涨跌、年度表现、重大回撤和季节性。
- `assets/app.js` 维护页面控制、渲染、报告和第三方数据交互。
- 原首页从 210,452 字节降到 24,079 字节，结构文件体积下降 88.6%。

## 独立测试

`tests/core.test.js` 无需浏览器即可验证：

- UTC 日期跨月、闰年和跨年计算。
- 样本最高价、距高点天数和收盘回撤。
- 前一日回撤与单日变化。
- 首次、连续、重复和中断后的本地观察记录。
- 下跌、上涨、振幅和插针四类条件触发，并覆盖缺少预计算字段时的 OHLC 回退公式。
- 乱序日线排序、样本高点、事件阈值、1/7/30 日未来样本数和上涨概率。
- 事件筛选使用未四舍五入原值，缺少未来日线的事件不进入概率分母。
- 回测模块可在不创建 DOM 的情况下接收任意日线与参数，页面只负责读取控件并渲染结果。
- 报告统计模块可使用确定性小样本复算，报告弹窗只负责组合文案与视觉输出。

`tests/index-regression.test.js` 会按线上资源顺序加载数据、计算核心和应用控制器，并验证三个模块均被首页和离线缓存正确装配。

## 架构预算与接口契约

`scripts/check-architecture.js` 已进入 `npm test` 和 CI，自动限制：

- `index.html` 不超过 30KB，禁止重新内联样式。
- `assets/app.css` 不超过 45KB，页面结构与视觉规则保持分离。
- 页面控制器不超过 150KB；事件核心、回测核心和报告核心分别不超过 16KB、14KB 和 10KB。
- 首屏五币种摘要不超过 8KB，防止重新同步加载完整多币种历史。
- 三个纯计算模块的公开函数名称与类型保持稳定，接口缺失立即失败。
- 控制器必须使用本站白名单行情接口，不得恢复旧任意代理。
- 报告渲染器必须保持按需加载，不能重新进入首屏。

当前最大预算占用为页面控制器 93.3%；已接近拆分阈值，后续功能必须优先提取模块，不能继续无界增长。

数据源扩展性也经过真实验证：实时行情主源与备用源在服务端标准化为同一浏览器数据契约；每日五币种摘要由统一配置生成，新增来源不需要复制页面。
