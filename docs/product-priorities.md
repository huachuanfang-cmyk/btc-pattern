# My BTC Box 产品优先级记忆

> 本文保留早期产品决策背景。当前强制执行标准见 `docs/quality-standard-95.md`，实时评分见 `quality-scorecard.json`。

更新时间：2026-05-19

## 产品定位

My BTC Box 不要先做成另一个交易所 K 线站。交易所已经把实时交易图表做得很专业，我们很难在 K 线深度、撮合数据、盘口、稳定性上超过 Binance、OKX、TradingView。

更适合的定位是：给加密圈小白看的“市场风险 + 历史规律工具箱”。用户打开后能快速知道今天市场热不热、哪个币异动、历史上类似情况后来怎么走。

## 第一优先级：小白每日打开会看的

这些功能要放在首页第一屏或接近第一屏，目标是让用户每天扫一眼。

1. 今日市场看板
   - BTC 大盘温度或恐惧贪婪类指标。
   - BTC/ETH/SOL/DOGE/BNB 的实时价格、24H 涨跌、距离历史高点。
   - Funding、多空比这类情绪数据只保留稳定、解释清楚的数据源。

2. 5币种实时热力条
   - 展示 24H 涨跌、距 ATH、简单状态标签。
   - 作用是快速比较，不承担交易所 K 线功能。
   - 点击行为后续可以考虑跳到该币种历史查询，而不是打开复杂 K 线。

3. 今日异动榜
   - 谁跌最多、谁涨最多、谁距离 ATH 最远、谁触发了历史样本。
   - 文案要小白化，例如“今天 DOGE 跌幅最大，已回到历史高点下方 85%”。

4. 浏览器本地提醒
   - 价格到达某个点提醒。
   - 单日跌幅超过 3%/5%/8% 提醒。
   - 距历史高点回撤到某个比例提醒。
   - 前期先做本地浏览器提醒，不急着做账号系统。

## 第二优先级：网站的差异化

这些是 My BTC Box 跟普通行情站不一样的地方，应该继续强化。

1. 历史事件查询
   - 单日收盘大跌、大涨、振幅、插针。
   - 保持清楚的数据口径：Yahoo Finance UTC 日线。
   - 明确区分收盘口径、最高价口径、最低价口径。

2. 条件买入回测
   - 保留条件买入 vs 定投对比。
   - 年度、月度、最大回撤、胜率继续作为核心展示。
   - 文案持续强调：不是交易信号，只是历史观察。

3. 报告卡片
   - 适合分享到微信、微博、X。
   - 加入“4周期关键数据”这类简洁模块，但不要塞太多表格。
   - 报告要比页面更像一张可传播的结论图。

4. 5币种日期快照
   - 保留“点击历史日期查看5币种同日表现”。
   - 这是历史查询里的差异化功能，比普通行情站更有记忆点。

## 第三优先级：可以后面做

这些有价值，但先不抢前期节奏。

1. 本地持仓观察
   - 用户输入买入价和数量，在本地浏览器保存。
   - 展示盈亏、距 ATH、如果回到某价格的收益。
   - 不做账号，不上传用户资产。

2. 小白风险词典
   - Funding、多空比、ATH、回撤、插针、振幅、强平等。
   - 每个词用一句话解释，不写成百科。

3. 稳定的衍生品数据
   - 爆仓、全网多空、资金费率可以做，但必须有稳定数据源。
   - 如果纯前端直连交易所 WebSocket 不稳定，先不要放在首页核心位置。

4. 高级图表
   - 如果要做 K 线，应该使用成熟图表库或第三方嵌入，而不是手写一套交易所级图表。
   - 只有当它能明显服务“历史规律/小白判断”时再做。

## 暂时不做或先移除

1. 交易所级 K 线克隆
   - 容易分散定位。
   - 数据源、交互、性能、移动端体验都要求很高。
   - 用户真要深度看 K 线，会直接去 Binance、OKX 或 TradingView。

2. 不稳定的爆仓雷达
   - 如果连接经常失败或长期显示 0，会降低用户信任。
   - 后续要做也应改成“明确数据源 + 明确延迟 + 明确范围”的模块。

3. 没有解释的数据堆叠
   - 小白用户不是缺数据，而是缺一句能看懂的判断。
   - 每个指标都要回答：这对今天有什么用？

## 线上与本地对比

截至 2026-05-19 打开线上首页，线上版主要包含：

- 历史事件查询。
- 条件买入回测。
- 5币种选择。
- 5币种日期快照。
- 报告卡片分享。
- CoinGecko 实时价格入口。
- Yahoo Finance OHLCV 数据说明。

当前本地实验版曾额外加入：

- BTC 大盘温度。
- 实时市场观察。
- 5币种实时热力条。
- OKX K线图试验。
- Binance/爆仓雷达试验。

当前决策：

- 保留市场温度、实时市场观察、5币种热力条，作为第一优先级方向继续打磨。
- 先移除本地 K 线图试验和不稳定爆仓雷达相关入口，避免产品方向混乱。
- 后续按优先级一点点加入，不急着把首页做成行情终端。

## 下一步实施顺序

1. 清理本地 K 线和爆仓雷达实验代码。
2. 打磨“今日市场看板”文案和稳定性。
3. 强化 5币种热力条，让它更像每日打开的入口。
4. 增加今日异动榜。
5. 增加本地浏览器提醒。
6. 再回头优化报告卡片和4周期关键数据。
