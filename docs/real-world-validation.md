# My BTC Box 真实世界验收方案

更新时间：2026-08-13

这份方案用于补齐无法由自动测试替代的三项证据：产品定位理解、真实用户回访、搜索平台收录。不得由项目开发者代替目标用户填写，也不得用机器人流量代替真实回访。

## 一、5 名目标用户的 10 秒定位测试

对象：知道 BTC 或加密货币，但不是专业量化开发者的普通用户。至少 5 人，每人第一次看到网站。

流程：

1. 打开 `https://www.mybtcbox.com/`，只看 10 秒，不操作。
2. 隐藏页面，让参与者用自己的话回答：“这个网站主要帮你做什么？”
3. 记录原话，不提示“不预测”“历史数据”“工具”等关键词。
4. 再让参与者完成四项任务中的两项，记录是否完成、用时和卡点。

定位回答满足以下三点即通过：

- 提到查询、比较或理解历史数据。
- 没有认为网站在预测下一次涨跌或提供买卖信号。
- 能说出至少一个具体用途：查历史事件、比较周期、跑回测或生成报告。

升级到 9.5 的门槛：至少 5 人完成，10 秒定位理解成功率不低于 80%；任务成功率不低于 95% 时使用自动任务证据补充。

建议记录字段：日期、参与者编号、是否首次访问、10 秒原话、定位是否通过、任务、完成时间、是否完成、卡点。不得记录姓名、钱包地址或联系方式。

空白记录模板见 `docs/templates/user-test-template.csv`，现场填写说明见 `docs/templates/user-test-guide.md`。模板只能记录真实测试，不得预填示例参与者冒充证据。

## 二、匿名回访观察

只有用户在 `/privacy.html` 主动开启后才进入统计。GA 事件名为 `retention_milestone`，允许字段只有：

- `milestone`: d0 / d1 / d7 / d30
- `installed`: yes / no
- `saved_query_bucket`: 0 / 1-2 / 3-5
- `data_fresh`: same_day / completed_daily

每周固定导出聚合数量，分母采用同期 D0 用户；D7 回访率 = 到达 D7 的匿名用户数 / 已经有资格到达 D7 的 D0 用户数。新用户未满 7 天时不得进入分母。

升级到 9.5 的门槛：至少一个完整 30 天窗口；D7 回访率达到 20%；开启、撤销、默认关闭和失败降级持续通过自动测试。

## 三、搜索收录与自然访问

每周检查：

- 首页、工具目录、六个工具 URL、方法页与数据状态页是否已收录。
- canonical、抓取状态、结构化数据错误和重复页面原因。
- 自然搜索曝光、点击、CTR，以及进入后是否触发核心任务。

升级到 9.5 的门槛：核心工具 URL 被搜索平台抓取且无阻断错误；Dataset、WebApplication 与 Breadcrumb 无结构化数据错误；保存至少 30 天自然搜索证据。公开 `site:` 搜索只能作为辅助，不替代 Search Console。

## 评分纪律

- 未达到观察窗口时保持当前分数，不按功能数量加分。
- 自动测试证明“系统能够测”，真实数据证明“用户确实使用”。两者不可互换。
- 所有结果写入 `docs/evidence/`，评分变动同时更新 `quality-scorecard.json`。
